How do I return to an earlier Active Study session?

Use exit with save, then open the same sheet with the same difficulty and style to resume. Custom session settings stay saved, and offline results only count once the server confirms them.

Availability

A prepared sheet with published questions for the chosen difficulty. Customization and the Pomodoro style are available in the Focus reader only for new sheets prepared with a page-based question bank.
