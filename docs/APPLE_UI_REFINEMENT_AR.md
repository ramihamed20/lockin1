# واجهة أبسط للطالب

27 أكتوبر 2026 — متابعة تطوير الإعدادات في PR #73 فوق PR #72.

أصبح اسم الصفحة في الشريط العلوي كافيًا للصفحات الأساسية؛ يبقى عنوان دلالي واحد لقارئ الشاشة. أزيلت العناوين التمهيدية المكررة من جذور الإعدادات والمواد والأسئلة والمراجعة والإشعارات والتقدم والاشتراك، مع بقاء أسماء المواد والشيتات والرجوع في الصفحات الداخلية. بطاقة متابعة الدراسة تعرض الشيت أو فعل البداية مباشرة.

في الإعدادات، أزيلت بطاقة الإشعار التجريبية والشروح المتكررة تحت عناوين الأقسام والروابط. بقيت المجموعات مسماة لقارئ الشاشة، والبحث والروابط المباشرة والتركيز عند الدخول والرجوع. أصبح شرح التعرف على الأجهزة قابلًا للفتح عند الحاجة. بقيت معلومات الأذونات والحفظ وأمان الحساب والدفع والحذف ظاهرة.

الألوان المشتركة أهدأ: خلفية فاتحة رمادية وبطاقات بيضاء مسطحة، ودرجات داكنة أكثر تمييزًا، وعناوين الأقسام 20–22 بكسل. ظلت ألوان الهوية والثيمات والأيقونات ومقاسات اللمس الأساسية محفوظة.

## التحقق

- نجحت اختبارات Node الكاملة: 805 حالات، بما فيها تباين النص على الأسطح الفاتحة والداكنة.
- نجحت 72 حالة متصفح مختلفة عبر التشغيل الأساسي وإعادة تشغيل الحالات الأربع بعد تصحيح بيانات الاختبار. شملت الإعدادات والأمان والتنقل ولوحة المفاتيح، العربية والإنجليزية، الهاتف والآيباد والكمبيوتر، وعدم التمرير الأفقي وبقاء عنوان دلالي واحد.
- صُححت توقعات اختبارين قديمين لموقع تعريف أقسام الإعدادات، واختبار كلمة المرور ليفتح قسم الأمان الحالي. لا تغييرات في وظائفهما.
- نجح اختبار Django المستهدف بعد تثبيت ساعة إنشاء الاشتراك التجريبي مع ساعة القراءة في الاختبار نفسه؛ هذا إصلاح لبيانات الاختبار فقط.
- نجحت إعادة الحالات الثماني الجديدة على البناء الإنتاجي النهائي، مع مراجعة صور الهاتف والآيباد. نجحت TypeScript وESLint والبناء وفحص الحزمة والأدلة العامة و`git diff --check`؛ حجم JavaScript الابتدائي 159.9 KiB gzip وCSS 94.2 KiB gzip.

اختبارات المتصفح تستخدم حسابات وبيانات مصطنعة. التحقق المحلي في Chromium لا يمثل اعتماد Safari أو جهاز Apple فعلي. لا ترحيلات أو تغييرات في API أو صلاحيات أو منطق دفع أو دراسة، ولا نشر تلقائي إلى الموقع العام.
