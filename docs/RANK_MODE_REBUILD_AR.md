# إعادة بناء Rank Mode

التاريخ: 26 أكتوبر 2026. الأساس: `main` عند `7ff702c`.

## السلوك الجديد

- فتح `/ranked` من سجل إتاحة المنتج مع واجهة عربية وإنجليزية مناسبة للهاتف والآيباد والكمبيوتر.
- ترتيب فردي من نقاط التعلّم المؤهلة المسجلة على الخادم، باستخدام `RankingFact` الموجود. لا تغيير لمقادير XP أو مصادر منحها.
- المنافسة داخل الدفعة الحالية، مع اشتراط تطابق دفعة الطالب ودفعة دليل النقاط. الحساب غير المرتبط بدفعة لا يرى ترتيبًا عامًا بديلًا.
- الأسبوع الافتراضي يبدأ الاثنين 00:00 بتوقيت ليبيا، مع الفترة الشهرية والإجمالي. تعرض المواعيد بتوقيت ليبيا حتى لو اختلف توقيت الجهاز.
- يتحدث الترتيب عند فتح الصفحة أو الضغط على تحديث؛ لا يعتمد على نشر الأدمن للقطات ولا توجد وعود بتحديث لحظي تلقائي.
- عرض أول 100 طالب، ومركز الطالب منفصلًا إذا كان خارج القائمة، والفارق للوصول إلى المركز الأعلى. التعادل يعطي المركز نفسه بنظام 1، 1، 3.
- إعدادات الأسماء: الاسم الكامل أو الأحرف الأولى أو الاسم المجهول. إيقاف المشاركة يخفي الطالب ويحافظ على دليل نقاطه. ينطبق الإخفاء أيضًا على واجهة اللقطات القديمة.
- معالجة التحميل، الفشل وإعادة المحاولة، غياب الدفعة، عدم وجود نقاط، وفشل حفظ الخصوصية. تبقى مسودة الخصوصية عند تبديل الفترة.

## حدود النطاق

هذه النسخة تعيد بناء التصنيف الفردي. تبقى صفحات Lockin Mode وSolo/Team والفرق والجلسات الموجودة في مواضعها؛ لم تُفتح بوابة جلسات الفرق ولم تُستبدل بمنتج آخر. لا تُنشأ رتب معدنية أو جوائز أو قواعد نقاط جديدة.

## البيانات والعقد

واجهة جديدة متوافقة مع الواجهات الموجودة:

`GET /api/v1/progression/rankings/live?period=weekly|monthly|all_time`

تتطلب جلسة مصادقًا عليها، وترفض كتابة النقاط. ترجع الفترة وحدودها والدفعة وعدد المشاركين وأول 100 ومركز الطالب وفارق النقاط، مع `Cache-Control: private, no-store`. يجري التجميع والترتيب في قاعدة البيانات. عدد الاستعلامات محدود ولا يزيد باستعلام لكل مشارك.

المهاجرة `rankings.0003_anchor_evidence_to_cohort` تضيف دفعة إلى دليل النقاط وفهرسًا للتصفية. تحفظ الدفعة عند اكتساب النقاط الجديدة حتى لا تنتقل نقاط سنة سابقة عند تغيير بيانات الحساب. الأدلة القديمة لم تسجّل دفعتها تاريخيًا؛ تعتمد المهاجرة دفعة صاحبها الحالية أساسًا، ولا يمكنها استعادة انتماء غير مسجل في الماضي. الأدلة القديمة التي لا يملك صاحبها دفعة تبقى غير منسوبة. لا تُحذف نقاط أو لقطات موجودة.

## التحقق

- 24 اختبار خادم ناجح: التصنيف والفترات وحدود توقيت ليبيا، العزل بين الدفعات، تغيير الدفعة، ترحيل الأدلة القديمة، الخصوصية واللقطات القديمة، التعادل، المركز بعد أول 100، إزالة التكرار، الدليل الملغى والمستقبلي، صلاحيات API وميزانية الاستعلامات؛ وتشمل اختبارات محركات XP والتكامل القائمة.
- 12 اختبار متصفح ناجح تغطي الهاتف 375 والآيباد 820 والكمبيوتر 1440، العربية/RTL والإنجليزية، الفترات الثلاث، عدم تجاوز عرض الشاشة، الخصوصية والإخفاء والعودة، أخطاء الحفظ والتحميل، والدفعة الفارغة أو غير المحددة.
- 14 اختبار Node ناجح لبوابة الميزات ودليل الموقع العام وطلبات التقدم القائمة.
- فحص Django، وعدم وجود انجراف مهاجرات، وRuff وmypy للخلفية وESLint وTypeScript للواجهة، والبناء القياسي وبناء المتصفح.

اختبارات قاعدة البيانات استعملت استثناء SQLite الصريح في المستودع. لم يُجر اختبار PostgreSQL أو CI أو ترحيل إنتاجي في هذه الجلسة. اختبارات المتصفح تستخدم حسابات وبيانات مصطنعة مع واجهات API محاكية؛ اختبارات الخادم تتحقق من الحسابات الفعلية. لم تُختبر أجهزة iPhone/iPad فعلية. لم يُنفذ نشر أو دفع أو دمج على GitHub أو VPS.

## إكمال التفعيل على الإنتاج

يتطلب الإصدار اجتياز CI على PostgreSQL، وتشغيل المهاجرات المعتادة ضمن نشر صورة الخلفية ثم الواجهة من الإصدار نفسه. فحص الدفعة والنقاط القديمة والخصوصية بحسابات اختبار بعد النشر يثبت جاهزية التشغيل الحي. لا يُنشر مجلد `dist` المبني لاختبارات E2E.

## تحسين الواجهة — 26 أكتوبر 2026

أُعيد تنظيم التصنيف حول أسلوب Lock-in V2 القريب من التطبيقات الأصلية: عنوان كبير، سطح واحد لمركز الطالب ونقاطه، وأقسام قائمة ذات فواصل داخلية. يستخدم التصميم ألوان النظام بحسب الثيم المختار، مع لون الإجراء الرئيسي فقط؛ لا توجد ألوان أو خطوط أو مكتبات جديدة.

- استُبدلت مفاتيح الفترة القديمة بـTabList المشترك، مع اختيار متحرك وتحكم بأسهم لوحة المفاتيح.
- أضيف مؤشر تقدّم فعلي: النقاط الحالية مقابل نقاط أقرب مركز أعلى. يظهر فقط عند وجود مركز أعلى وبيانات كافية؛ لا تُعرض نسب مصطنعة للقائد أو الحساب المخفي.
- زر «مكاني» ينقل التركيز إلى صف الطالب، بما في ذلك المركز خارج أول 100، مع احترام تقليل الحركة.
- أصبحت الخصوصية والقواعد مجموعتين قابلتين للفتح، مع مفتاح Switch وخيارات اسم بصفوف اختيار وعلامة صح. يبقى الحفظ صريحًا وتبقى المسودة عند تغيير الفترة.
- أُضيف هيكل تحميل يحافظ على تنظيم الصفحة، ورابط للملف الشخصي عندما لا توجد دفعة.
- انتقلت أنماط Rank Mode إلى القسم المخصص في `styles/v2.css` وفق دليل تصميم المشروع، وأُزيل ملف الأنماط القديم. لا تغيير للخلفية أو النقاط أو واجهات API.

التحقق الخاص بهذا التحسين: 17 اختبار متصفح ناجح (12 للتصنيف و5 لبوابات الميزات المجاورة)، و10 اختبارات Node ناجحة، وESLint ومشروعا TypeScript. تشمل أحجام العرض 320 و390 و667 أفقيًا و820 و1180 و1440، العربية والإنجليزية، الثيمين النهاري والليلي، والتحكم بلوحة المفاتيح وتقليل الحركة. صور الاختبار تعرض بيانات مصطنعة فقط. الاختبارات في Chromium بمحاكاة الأحجام؛ لم يُستخدم جهاز Apple فعلي أو WebKit في هذه الجلسة. البناء القياسي وميزانية الحزمة فُحصا قبل حفظ التغيير. لا يزال التنفيذ محليًا على فرع `codex/rank-mode-rebuild`.
