# إصدار واجهة Study Plan

هذه دفعة تحسين واجهة الخطة الحالية في 0.1.4. لا تضم أساس بيانات Study Plan 2.0 أو إدارة الامتحانات أو ترحيلاته، ولا تقدم توليدًا تكيفيًا أو إكمالًا تلقائيًا عبر Active Study.

## التغييرات

- إبراز الجلسة القادمة مع إجراء بدء واضح.
- عرض التقدم الأسبوعي من الدقائق المكتملة المسجلة، مع بقاء الإنجاز تسجيلًا شخصيًا لا يمنح XP أو يثبت الإتقان.
- تقويم أسبوعي ومهام أوضح، وإعدادات محسنة تدعم العربية والإنجليزية والسمات الحالية.
- أهداف لمس لا تقل عن 44 بكسل لأيام الأسبوع، وتمرير محلي للتقويم يحافظ على ظهور اليوم المحدد عند تغيير حجم الشاشة دون تحريك الصفحة.

## عقد الإصدار

لا تعديل في عقد API أو الاشتراكات أو قاعدة البيانات أو الاعتماديات. جلسات الطلاب القديمة وتقدمهم يستمران عبر الخدمات الحالية. الاختبارات تستعمل بيانات تجريبية؛ لا تُضاف هذه البيانات إلى التطبيق أو الإنتاج.

يُراجع الفرع `codex/study-plan-visual-release` فوق `codex/lockin0.1.4`. بعد نجاح بوابات GitHub المعتادة ودمج المراجعة، يُبنى الإصدار عبر CI وتُسحب الصور الجاهزة وفق مسار المشروع المعتاد. لا تتطلب هذه الدفعة وحدها أي ترحيل أو متغير تشغيل جديد.

التراجع يكون بإرجاع تعديلات الواجهة عبر Git وبناء صورة سابقة معتمدة، دون تغيير بيانات الطلاب. لا تنفذ هذه الدفعة دمجًا أو نشرًا على الخادم.

## التحقق

```text
pnpm install --frozen-lockfile
pnpm run lint
pnpm run typecheck
pnpm test
pnpm run build
pnpm run check:bundle
```

اختبارات المتصفح تستعمل بناء إنتاج عاديًا دون كتالوج E2E، وتغطي أوضاع الخطة الثلاثة، الحفظ وإعادة الفتح، فشل الحفظ وإعادة المحاولة، تعارض التعديلات، الجلسات المتأخرة، حماية مسارات الميزات، العربية والإنجليزية، الهاتف والآيباد والكمبيوتر والوضع الأفقي، وإبقاء اليوم المحدد ظاهرًا عند تغيير المقاس.

هذه أدلة Chromium في بيئة محلية؛ لا تحل محل اختبار Safari أو أجهزة iPhone/iPad الفعلية. تبقى بوابات CI الكاملة شرطًا للدمج وفق إعدادات المستودع.

نتيجة الفحص المحلي: تثبيت ملف القفل نجح، و793 اختبار وحدة و18 اختبار متصفح على بناء الإنتاج نجحت، مع نجاح ESLint وفحصَي TypeScript وبناء الإنتاج. أحجام الدخول المضغوطة: JavaScript نحو 160.7 KiB وCSS نحو 92.7 KiB، ضمن ميزانيات المشروع. لا توجد تغييرات على الباك إند في هذه الدفعة.
