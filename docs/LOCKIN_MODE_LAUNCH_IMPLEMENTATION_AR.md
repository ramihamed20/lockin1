# تطوير Lockin Mode — 27 أكتوبر 2026

هذا الفرع يحسن أساس Solo وTeam وتجربة الدراسة، ولا يعلن نشرًا أو جاهزية إطلاق عام.

## المنفذ

- بوابة إتاحة من الخادم مع تفعيل اختياري لحسابات تجربة، وإبقاء الجلسات الموجودة قابلة للاستكمال عند إيقاف إنشاء جلسات جديدة.
- تجربة V2 مع هدف، مادة، صفحات ومدة مخصصة، وربط بقارئ Focus الحالي عبر رابط مصدر يعاد التحقق منه. يظهر مؤقت ورابط عودة داخل القارئ.
- وقت مشاركة خاص لكل عضو؛ العضوية وحدها لا تمنح حضورًا. الاستراحة والخروج والعودة لا تضاعف الزمن؛ النبضات المتأخرة مقيدة بمهلة 75 ثانية وبنهاية الجلسة.
- عداد يعتمد على الزمن الرتيب في المتصفح، ومصالحة مع الخادم وإصدارات الاستجابة لمنع إعادة حالة قديمة.
- تسوية نهاية الجلسة عند موعدها الفعلي عبر القراءة أو المجدول الحالي، مع إعادة حساب موعد انتهاء Solo بعد الاستئناف.
- إصدار أحداث الإنجاز لكل مشارك مستحق مرة واحدة، وتحديث ملخص الوقت وإعادة بناء أدلة التحفيز من السجل الشخصي. أسعار XP لم تتغير.
- إصلاح تضاعف مجموع وقت الفرق؛ جلسات متساوية المدة تبقى محسوبة مستقلة. ترتيب الفرق والأفراد مقيد بالدفعة في API.
- ملاحظات خاصة لكل مشارك مع فحص الإصدار؛ نقاش نصي اختياري يستخدم خدمة رسائل الفريق القائمة. النقاش لا يصحح الإجابات ولا يمنح نقاط تعلم.
- صلاحية يوم للأكواد الجديدة/المجددة، وحد عشر محاولات انضمام لكل حساب خلال عشر دقائق، محفوظ في قاعدة البيانات عبر العمال.
- تبسيط الواجهة وتحسين حجم لمس إزالة العضو، وحفظ واجهات V1 لاستعادة البيانات القديمة دون منح مكافآت مشاركة بأثر رجعي.

## التشغيل

تطبيق مهاجرتي focus 0021 و0022 قبل تشغيل الصور الجديدة. تشغيل web وoperations-scheduler من الإصدار نفسه؛ أضيفت مهمة settle_lock_in_sessions بعد مهمة البريد، مرة كل دقيقة افتراضيًا. يعتمد توقيت الإغلاق المسجل على الموعد الخادمي وليس على تأخر تشغيل المهمة.

`LOCKIN_MODE_ENABLED` افتراضيًا false. يمكن استعمال `LOCKIN_MODE_PILOT_USER_IDS` لقائمة معرفات حسابات مفصولة بفواصل. التفعيل العام قرار نشر منفصل. إنشاء جلسات V1 جديدة مرفوض في الإعداد الإنتاجي؛ يلزم تحديث العميل، بينما تبقى الجلسات القديمة قابلة للاستعادة. إعداد السماح بإنشاء V1 موجود في اختبارات التوافق فقط.

الحضور يدل على حالة التطبيق، ولا يثبت انتباه الطالب أو إتقانه. الانقطاع الطويل لا يتحول إلى ساعات تنافسية تلقائية. الملاحظة الخاصة تحفظ بزر صريح، وتبقى أخطاء الحفظ ظاهرة.

## حدود الإطلاق

لم تنفذ دورة أسئلة مشتركة ذات محاولة فردية ثم نقاش ثم سؤال جديد؛ تتطلب ربطًا بمحتوى معتمد ومواصفة منفصلة. التكامل الحالي يفتح القارئ وأدوات الدراسة الموجودة. لم تُضف غرف عامة أو مكالمات أو خوارزمية مطابقة أو تقييم آلي طبي، ولم تُعدّل فروع Study Plan أو الإشعارات أو الإعدادات المفتوحة.

يلزم نجاح PostgreSQL CI قبل الدمج: التحقق المحلي باستخدام SQLite لا يثبت صحة الأقفال أو غياب التعارضات. يلزم اختبار Safari على iPhone وiPad فعليين، وحمل إنتاج مناسب. لا توجد شهادة وصول إشعار فعلي أو جاهزية عالمية في هذا الفرع.

## التحقق

اجتازت الاختبارات المحلية 28 حالة API/خادم ضمن عائلة Lockin، و796 اختبار Node، وESLint وTypeScript، وRuff وفحص Django وانعدام انحراف المهاجرات، وmypy لست وحدات backend. نجح البناء العادي وحدود حجم الحزمة: نحو 160 KiB JavaScript و93.1 KiB CSS بعد gzip.

تجربة المتصفح تستخدم API fixtures ولا تعادل Django حقيقيًا أو جهاز iPad فعليًا. تفاصيل نتيجة التشغيل النهائي موثقة في وصف PR. راجعت فروق App والقارئ والترجمة مقابل مستهلكي الأدلة العامة؛ الإضافات لا تغير الادعاءات العامة القائمة، وحُدثت بصمات الملفات الثلاثة بعد المراجعة مع إبقاء بوابة الأدلة إلزامية.
