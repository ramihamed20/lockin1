# تطوير إعدادات Lockin

التاريخ: 26 أكتوبر 2026
فرع العمل: `codex/settings-apple-redesign`

## نتيجة المراجعة

كانت إدارة الحساب تجمع تغيير كلمة المرور والجلسات والحذف في صفحة واحدة، وسجل الدفع محصورًا في صفحة الاشتراك. أسماء الأجهزة عامة، وقنوات الإشعارات تكرر التصنيف في كل سطر. كانت حسابات Google وApple تُعرض كغير مرتبطة دون مصدر يثبت حالة ارتباط حساب المستخدم.

أصبح التنظيم بقوائم مجمعة هادئة وأيقونات ملوّنة ومفاتيح تبديل مشتركة، مع المحافظة على هوية Lockin والثيمات الحالية. الهاتف والآيباد العمودي يعرضان قائمة ثم تفاصيل، والشاشات العريضة تعرض قائمة جانبية قابلة للتمرير بجوار القسم.

| القسم | ما يمكن للطالب فعله |
| --- | --- |
| الحساب | الوصول للملف وتغيير اسم المستخدم والتنقل إلى إدارة الحساب |
| تسجيل الدخول والأمان | تغيير كلمة المرور وطلب تغيير البريد بكلمة المرور الحالية، ثم تأكيد البريد الجديد |
| أجهزتك | رؤية رسم الهاتف أو الآيباد/التابلت أو الكمبيوتر، معرفة الجهاز الحالي وآخر نشاط وتواريخ الجلسة، وإنهاء جلسة أو تسجيل الخروج من الجميع بعد التأكيد |
| الاشتراك والمدفوعات | رؤية الاشتراك، وتصفح صفحات سجل الدفع وتفاصيل العملية والمبلغ والطريقة والاسترداد وملاحظة الرفض، والوصول لإدارة الاشتراك والاسترداد |
| الخصوصية وبياناتك | تنزيل التصدير الشخصي، طلب حذف الحساب وإلغاء الطلب، وفتح سياسات الخصوصية والاستخدام والاسترداد |
| المظهر | الثيمات والتبديل التلقائي واللغة وشخصية الدراسة وأيقونة التطبيق |
| الإشعارات | حالة إشعارات الجهاز والتفعيل والاختبار الموجودان، موعد التذكير والمنطقة الزمنية، وقنوات كل تصنيف في مجموعة مستقلة |
| بقية الإعدادات | التنزيلات والعمل دون اتصال، المواد الإضافية للمؤهلين، الاقتراحات، التحديثات، عن Lockin والدعم |

يبحث حقل الإعدادات في أسماء الأقسام وما داخلها بالعربية والإنجليزية، ويتسامح مع اختلاف الهمزات والتشكيل. الروابط القديمة للمظهر والتذكير وكلمة المرور ما زالت تعمل. رابط حذف الحساب يفتح الخصوصية ويزيل رمز التأكيد من العنوان بعد معالجته.

## السلوك ومصادر البيانات

- بيانات الحساب والجلسات والإشعارات والدفع تأتي من واجهات الخادم الحالية؛ لا توجد مدفوعات أو أجهزة تجريبية مدمجة في المنتج.
- سجل الدفع يطلب عشر عمليات لكل صفحة، ويعتمد الحالة المالية النهائية قبل حالة المراجعة القديمة. لا يحتاج نجاح طلب الكتالوج أو الفواتير أو الاستردادات لتحميل السجل، ولا يتبع عناوين الصفحات التي يعيدها الخادم إلى مواقع أخرى.
- نوع الجهاز تقديري. تُحسّن أسماء الجلسات الجديدة من اسم المتصفح ونوع الجهاز دون حفظ User-Agent كامل. يمكن التعرف على الآيباد في وضع سطح المكتب للجلسة الحالية باستخدام معلومات المتصفح المحلية؛ لا تُطبّق هذه المعلومات على الجلسات الأخرى ولا تُدّعى معرفة طراز الجهاز.
- تُحفظ أيقونة التطبيق على المتصفح، ويستمر اختيارها بعد إعادة التحميل. لا يُرسل طلب تعديل ملف شخصي لاختيار الأيقونة. الثيم واللغة يحتفظان بآلية الحساب الحالية، وتُسلسل طلبات الثيم لمنع التحديثات المتنافسة.
- الإشعارات المطلوبة تظل مقفلة، والقنوات غير المتاحة لا تُعرض كقابلة للتفعيل. حفظ التذكير لا يطلب إذن إشعارات المتصفح تلقائيًا.
- لا يغيّر طلب البريد العنوان الحالي قبل التأكيد. لا يُدّعى وصول الرسالة إلى صندوق البريد بمجرد قبول الطلب.
- تنزيل البيانات مستقل عن حالة الحذف وأخطائه. يبقى الحذف محميًا بكلمة المرور وتأكيد البريد وسياسة المعالجة الحالية، ولا تظهر رسالة توحي باكتمال الحذف لمجرد الطلب.
- أزيلت قائمة حالة ربط Google/Apple غير المستندة إلى بيانات الحساب. تسجيل الدخول عبر المزوّدين لم يتغير.
- لا تغييرات على نماذج قاعدة البيانات أو مخطط API أو الصلاحيات أو الاستحقاقات أو دفع الأموال. لا ترحيل قاعدة بيانات مطلوب لهذه التغييرات الإضافية فوق فرع الأساس.

## التحقق

اكتملت الاختبارات التالية؛ اختبارات المتصفح تعتمد بيانات مصطنعة معزولة، ولا ترسل بريدًا فعليًا ولا تنهي جلسات مستخدمين حقيقيين:

- 29 حالة Node مختلفة في مجموعات العقد والتصميم والترجمة والتجربة والمحتوى العام المختارة؛ منها 24 في التشغيل المباشر النهائي.
- 20 اختبار Django مختارًا نجح في وضع SQLite الصريح؛ شملت أسماء الأجهزة والجلسات والخروج والحذف وتغيير البريد. استُبعد 31 اختبارًا خارج اختيار التشغيل، واستُخدم `--no-cov` وفق إرشادات الاختبارات المستهدفة.
- 42 حالة متصفح مختلفة نجحت عبر التشغيل الأول وإعادة تشغيل الحالات المتأثرة ثم اختبارات الحالات الإضافية. شملت عرض 320 و390 و820 و1180 و1440 بكسل، العربية والإنجليزية، البحث والرجوع والتركيز، الرسوم والجلسات، سجل الدفع وصفحاته، الإشعارات والتذكير، تنزيل البيانات وتغيير البريد، ومنع تكرار تأكيد الحذف. أُعيدت ست حالات على البناء الإنتاجي النهائي ونجحت كلها.
- ESLint للملفات المتأثرة، مشروعا TypeScript، وRuff وmypy لملف خدمة الحساب: ناجحة.
- البناء الإنتاجي العادي وفحص حجم الحزمة: ناجحان؛ JavaScript الابتدائي 159.9 KiB gzip وCSS 94.3 KiB gzip ضمن الحدود الأصلية.
- التحقق الإلزامي من الأدلة العامة والمخرجات المولدة و`git diff --check`: ناجح. راجعت الشاشات بصريًا أثناء الاختبارات، وتبقى لقطات البيانات المصطنعة أدلة محلية للاختبار.

تعثر تشغيل المتصفح الافتراضي لغياب نسخته المطلوبة، فاستُخدم Chromium 133 المتاح محليًا بإعداد اختبار مؤقت، دون تغيير إعداد Playwright المتعقب. وصُحح توقع الاختبار ليقبل الفاصل العشري المحلي العربي. بعض حالات البدء البطيء نجحت عند إعادة تشغيلها بعامل واحد. لا يُفهم من ذلك اعتماد Safari أو ضمان زمن فتح ثابت.
